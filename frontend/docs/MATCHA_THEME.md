# 세이지 그린 · 말차 나이트 (2026-10-01)

사용자의 후속 피드백에 따라 라이트 배경의 크림/노란 기운을 줄이고 옅은 세이지 그린으로 조정한다. 추가 시안은 색 배치의 위계(옅은 배경 → 흰 카드 → 선택 영역 → 짙은 행동/근거)를 참고하며 파란 팔레트를 적용하지 않는다. 레이아웃·API·저장/확정 규칙은 변경하지 않는다.

| 역할 | 라이트 | 다크 |
|---|---|---|
| 기본 배경 | #F2F7F4 | #12140F |
| 카드/메뉴 표면 | #FFFFFF | #1A1D16 |
| 주요 행동 | #46704E | #A8C47C |
| 강한 그린/선택 표면 | #2E5038 / #DFEDE3 | #1F2719 |
| 장식·보조 강조 | #AFC7B4 | #A8C47C |

버튼·STAR·확정 상태는 공통 강조색을 사용한다. 선택 메뉴는 연한 배경과 그린 글자, 선택 테두리는 강조색으로 표시한다.
근거 스트립은 라이트에서 진한 녹색, 다크에서 차분한 올리브 표면을 사용한다.
본문·작은 설명·주요 버튼은 읽기 대비를 확인한다. 주의(앰버)·오류(레드)는 별도 의미를 유지한다.
인쇄는 기존 흰 배경 규칙을 사용한다.

## 적용·검증 순서

1. 기존 `theme-contrast` 검사의 라이트 배경·버튼·선택 영역·카드 표면 기대값을 새 조합으로 바꾸고 변경 전 실패를 확인한다.
2. `tokens.css`의 라이트 팔레트와 배경·글자·경계·근거 조합을 조정한다. 다크에서 공유하던 성공 토스트 색은 전용 원시 토큰으로 분리해 기존 값을 보존한다.
3. 정적 빌드의 대비·반응형·선택 표시 회귀 검사와 모바일/PC 시각 검사를 수행한다.
4. README와 검증 결과를 갱신하고 동일한 변경을 팀/개인 PR에 반영한다. 운영 배포의 실제 색을 확인한다.

## 세이지 조정 검증

정적 프로덕션 빌드의 테마·반응형·제품 UX E2E 17개가 통과했다. 리뷰 후 작성 이력의 현재 버전 날짜 검사를 추가했고, 라이트 4.234:1로 실패하는 것을 확인한 뒤 보조 글자를 `#586C5E`로 조정해 두 테마 모두 통과했다. 날짜/선택 배경 대비는 4.66:1, 인셋 대비는 4.79:1이다.

새 라이트 팔레트의 주요 화면 5개 × 390/1440px 10장과 다크 홈/상세 2장을 확인했다. 이 12장 캡처 중 pageerror는 0건이었다. 작성 이력의 실제 선택 행도 추가로 확인했다.

라이트 주요 버튼 대비는 5.69:1, 입력 경계는 기본 배경에서 3.15:1이다. 다크의 실제 의미 토큰 값과 성공 토스트는 이전 팔레트 그대로다.

## 이전 팔레트 검증 (크림 배경)
홈·카드·카드 상세·레포·랜딩을 라이트/다크와 390/1440px에서 캡처한 20장을 확인했다. 이 경로의 브라우저 pageerror는 0건이었다.

정적 프로덕션 빌드에서 `theme-contrast`·`responsive`·`product-polish` E2E 17개가 통과했다. 테마 기본 배경, 본문/보조 글자·버튼·선택 메뉴의 4.5:1 이상 대비, 320~1920px 가로 넘침, 선택 모서리/높이, 흰 로고, 모달 하단 동작을 확인한다. 색감 검사는 변경 전 두 테마에서 실패하고 변경 후 통과했다.

주요 버튼 대비는 라이트 6.06:1, 다크 9.58:1이다. 입력 경계는 배경 대비 3:1 이상이 되도록 별도 경계 토큰을 사용한다. 새 화면도 색을 직접 지정하지 않고 역할별 토큰을 사용한다.

설정 화면에서 실제 라디오 선택으로 다크 전환과 새로 진입 후 유지도 확인했다. 브라우저 오류는 없었다. 자동화 도구에서는 화면 아래 버튼을 클릭하기 전에 해당 영역을 스크롤해 클릭 위치를 확보했다.
