# 매칭 검색 입력 안정화

## 문제와 범위

검색 입력이 URL의 `q` 값에 직접 의존해 Router 전환이 입력보다 늦게 반영되면 타이핑한 값이 이전 값으로 돌아갈 수 있었다. 입력은 컴포넌트 상태로 즉시 반영하고 URL도 같은 이벤트에서 갱신한다. Router의 늦은 REPLACE 결과로 입력을 덮어쓰지 않는다. 검색은 이미 받은 목록을 거르며 별도 요청은 하지 않는다.

## 보존할 동작

- 필터 변경과 상세 이동은 최신 검색어를 사용한다. URL 쓰기를 debounce하면 즉시 상세 이동 후 뒤로 가기 시 이전 검색어로 돌아가는 문제가 있어 지연 저장하지 않는다.
- 뒤로/앞으로 가기와 링크 진입은 해당 URL의 검색어를 복구한다.
- 검색 초기화는 입력과 URL을 모두 비운다.
- 검색으로 AI 요청을 추가 호출하거나 백엔드 계약을 변경하지 않는다.
- develop 병합 시 기존 카드 이동, 공통 모바일 푸터, 랜딩 간격 문서를 유지했다.

## 검증

`e2e/matching-207.spec.ts`에 영문·한글 빠른 연속 입력, URL 반영, 상세→뒤로 가기, Escape 초기화 회귀 검증을 추가했다. 실제 실행 결과와 화면은 PR에서 기록한다.
