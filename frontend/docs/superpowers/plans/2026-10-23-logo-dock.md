# Logo dock implementation plan

**Goal:** 승인된 중앙 로고→헤더 이동 인트로를 모바일/PC에서 검토 가능한 Vercel preview로 제공한다.
**Architecture:** LandingBrand 컴포넌트가 로고 DOM과 Web Animations 수명주기를 맡고 LandingPage가 본문의 inert 상태와 공개 시점을 연결한다. 전용 CSS로 진입만 제어한다.
**Tech Stack:** React, TypeScript, CSS, Web Animations API, Playwright.

## Constraints
GitHub push 금지. 환경 파일 업로드 금지. 운영 도메인 유지. 기존 로고/API/로그인 유지. 동작 줄이기·오류 경로에서 즉시 접근 가능.

- [x] e2e/landing-intro.spec.ts: 중앙 시작→헤더 착지, 재방문/오류/동작 줄이기, Escape 건너뛰기 및 로그인 동작 검사. 먼저 실패 확인.
- [x] src/features/auth/LandingBrand.tsx: 로고와 취소 가능한 진입 타임라인. 화면 폭에 맞는 scale, 이미지 로드 완료 후 좌표 측정, resize/초점/실패에서 안전 종료.
- [x] LandingPage.tsx와 landing-intro.css: 본문 inert 및 순차 공개, 새 의존성 없이 기존 랜딩 CSS 보존.
- [x] 프로덕션 빌드/단위/관련 E2E, 320/390/768/1440px 양 테마 캡처 및 직접 시각 확인.
- [x] README/docs 갱신. 로컬 변경만 보존하며 Vercel preview 배포. 실제 preview 재검증 및 링크 제공.
