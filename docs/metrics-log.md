## AI 호출 기록 모델별 사용량 SQL (#488, 2026-10-28 준비)
- 무엇을: `ai_call.model_usage`(JSONB 목록)로 기간별·모델별 LLM 호출 수와 토큰을 센다. 값은 #488 AI·BE 가 배포된 뒤의 기록부터 있다. 그 전 기록과 LLM 을 쓰지 않은 호출은 NULL 이다.

- 어떻게:
  ```sql
  SELECT u->>'model' AS model, COUNT(*) AS requests,
         SUM((u->>'llm_calls')::int) AS llm_calls,
         SUM((u->>'input_tokens')::bigint) AS input_tokens,
         SUM((u->>'output_tokens')::bigint) AS output_tokens
  FROM ai_call, jsonb_array_elements(model_usage) u
  WHERE created_at >= date_trunc('month', now())
  GROUP BY 1 ORDER BY input_tokens DESC;
  ```
