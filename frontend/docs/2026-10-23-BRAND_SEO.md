# 로고 인트로 및 공개 랜딩 SEO 배포 계획

사용자가 인트로 디자인을 승인했고 SEO/SNS 메타데이터, PR, 운영 배포까지 요청했다.

- 승인한 로고 도킹 인트로를 최신 develop e33f463에 반영한다. 이전 테스트 전용 #385와 겹치지 않게 선택 메뉴 검사는 포함하지 않는다.
- 단일 사이트 설정과 Vite 빌드 플러그인으로 HTML 제목/설명/canonical/OG/Twitter/JSON-LD, robots.txt, 공개 /login sitemap을 생성한다. JavaScript 없이 메타데이터를 읽을 수 있어야 한다.
- Vercel 기본 운영 도메인을 사용하고 VITE_SITE_URL로 다른 운영 도메인을 명시한다. 팀 Compose는 SITE_ADDRESS를 프론트 빌드 인자로 연결한다.
- private routes의 서버 X-Robots-Tag와 클라이언트 noindex를 맞춘다. 인증/세션/API 계약은 건드리지 않는다.
- 원본 로고와 기존 색상으로 1200×630 공유 이미지를 HTML/CSS로 렌더링한다. 새 패키지는 추가하지 않는다.
- SEO 회귀 검사를 실패 확인→구현→통과 순서로 수행한다. 전체 정적/모바일/HTTP 계약 검사, 단위/타입/빌드와 코드 리뷰를 수행한다.
- README 및 트러블슈팅 갱신. 팀 PR 양식/리뷰어/스크린샷과 개인 PR 업데이트 후 Vercel production을 배포한다. 실제 HTML/robots/sitemap/이미지/응답 헤더 및 PC/모바일 기능을 확인한다.
## 구현 상세와 트러블슈팅
- `src/lib/siteMetadata.ts`가 브랜드 문구와 HTTPS origin 검증의 단일 출처다. `tooling/siteMetadataPlugin.ts`가 HTML과 robots/sitemap을 빌드 및 개발 서버에서 제공한다.
- 원래 build 폴더에 둔 플러그인은 저장소 공통 ignore 규칙에 걸렸다. 독립 코드 검토에서 발견해 tooling으로 옮겼으며 Git 추적 여부를 확인했다.
- OG 이미지 생성기는 HTML/CSS와 원본 로고를 렌더링한다. PNG는 커밋하므로 운영 빌드가 브라우저/폰트 네트워크에 의존하지 않는다.
- robots.txt에서 개인 화면의 크롤링 자체를 막지 않아 서버 noindex를 읽을 수 있게 한다. api/auth만 크롤링 제외한다. Vercel과 Caddy는 기존 API/인증/SPA rewrite를 유지하면서 개인 경로에 X-Robots-Tag를 추가한다.
- 최초 HTML은 공유용 서비스 설명만 포함한다. 개인 카드 제목/내용은 OG나 구조화 데이터에 넣지 않는다. 사이트맵은 공개 /login 하나이며 검색 기능·가격·평점은 만들어 넣지 않는다.
- 색인은 검색엔진이 결정한다. Search Console/Naver 소유권 확인과 사이트맵 제출, 기존 카카오/SNS 미리보기 캐시 갱신은 외부 관리 작업이다. SPA의 전체 본문 SSR/정적 사전 렌더링과 알 수 없는 경로의 서버 404 전환은 이번 배포 구조에서 변경하지 않았다. 공개 랜딩은 검색엔진의 JavaScript 렌더링을 사용한다.

## 검증
- 추가 전 비-JavaScript OG 검사 실패 확인 후 구현.
- 단위 48개 파일/358개 통과. 새 SEO/인트로 브라우저 검사 15개 통과.
- 독립 코드 검토의 추적 파일 문제 해결 후 추가 결함 없음.
- 320/390/768/1440px × 라이트/다크에서 중앙 로고와 완료 상태를 캡처했고 가로 넘침·페이지 오류가 없다.
- 전체 정적/모바일/HTTP 검사와 CI 및 운영 배포 결과는 PR에서 기록한다.
