# 2026-10-01 UX 정리 계획·판단

기준: 최신 develop d6d07a6을 기존 PR #61에 병합. #62 회상/인터뷰/마스킹 보호를 유지한다.

- 첫 화면: GitHub 커밋 기록과 연결된 STAR 카드 예시를 PC에서는 나란히, 모바일에서는 읽기 쉬운 순서로 표시한다. 결과가 비어 있는 사례를 유지한다.
- 만료 안내: 시작 버튼 근처의 짧은 상태 문구. 큰 안내 박스는 없앤다.
- 선택 행: 실제 border로 행 크기·구분선을 바꾸지 않고 내부 선택 표시를 공통 사용한다. 첫/중간/마지막과 키보드 선택 모두 검증한다.
- 경험 목록: PC에서 카드 사이 간격과 개별 둥근 표면을 사용한다. 홀수 카드도 지나치게 늘리지 않는다.
- 레포 상태: 정리 완료와 카드 건수를 별도 중립 배지로 구분한다.
- 문구: 답변하기/내용 보완하기, 작성 이력, 저장·확정 시점처럼 사용자 행동/실제 상태를 기준으로 한다. 기술 버전 정보는 이력 화면에서만 자세히 보여준다.
- 로고: 동일 원본 심볼의 흰 SVG 표현을 추가하고 랜딩/모바일/PC/접힌 메뉴에 공통 적용한다.
- 권한: read:user/repo의 식별자 표현은 동일한 code 배지, 허용 여부는 별도 상태 표시. API enum/필드 변경 없음.

복원 전체 중단, 선택 교체, disabled 칩, 실행취소 경합, 성공 전 커밋 이벤트, 검색 결과 건수는 수정한다.
후보 PATCH 후 캐시는 응답으로 즉시 갱신하고 재조회는 비동기로 처리해 전체 보드의 불필요한 잠금을 줄인다.
div의 aria-selected를 되살리는 대신 checkbox의 aria-checked를 유지한다.
모달 중앙 정렬은 전 화면에서 의도된 디자인이다. 짧은 화면과 큰 PC에서 모두 경계·스크롤을 검증한다.
재시도 날짜가 잘못된 경우 권한을 추정하지 않고 응답 갱신을 안내한다.

## 반영 내용
- 원본 로고를 포함한 흰 SVG를 생성해 동일 심볼을 유지한다. 두 테마·5개 화면·390/1440px 스크린샷 20장 확인, 런타임 오류 없음.
- 행별 선택은 2px 내부 표시로 통일했다. 중첩된 장식 Radio의 역할을 제거하고 실제 행의 radio/aria-checked를 사용한다.
- UI의 내부 코드명을 없애도 API의 AI_DRAFT/USER_EDIT 등은 유지되며 작성 이력 E2E에서 원본 보존을 확인한다.
- 재사용 useActionGate와 서버 PATCH 응답 캐시 반영으로 동시 요청과 늦은 재조회 잠금을 처리했다.
- 실행 취소가 막히면 토스트를 닫지 않고 이유를 표시한다. 거절/허용 모두 단위 검사한다.
- 로컬 5173은 다른 프로젝트가 사용 중이었다. PLAYWRIGHT_PORT=5176, 시각 검증 서버 5177로 분리하며 다른 서버를 종료하지 않았다.
- 타입 검사·단위 테스트 80개 통과. 정적 E2E는 PR 검증 결과에 기록한다.
- 최종 정적 E2E 47개 중 46개가 한 번에 통과했다. 변경한 답변 저장 문구의 옛 단언을 수정하고 해당 1개도 재통과했으며, 원문과 USER_SELECTED 출처를 API로 추가 검증했다.
- 별도 코드 리뷰의 실행 취소 경합을 수정하고 재검토에서 추가 중요 문제 없음.
