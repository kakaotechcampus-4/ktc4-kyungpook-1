# 접힌 메뉴 스크롤과 대기 단계 대비

최신 develop abca4d2의 연결 worktree를 사용한다. 접힌 64px 메뉴에서 좌우 padding 12px를 빼면 39px만 남아 44px 펼치기 버튼이 넘친다. 실제 scrollWidth 66px/clientWidth 63px와 두 테마의 대기 원형 대비 1.03/1.20:1을 재현했다.

데스크톱 접힘 상태의 padding을 줄여 44px 조작 영역이 들어가도록 하고, 사이드바는 세로 방향만 스크롤한다. 짧은 창에서 모든 메뉴와 프로필을 휠·키보드로 접근할 수 있어야 한다. 펼침·태블릿·모바일·로고·본문 배치는 보존한다.

스크롤바는 투명 트랙 위의 얇은 둥근 손잡이로 표시하고 hover 때 더 선명하게 한다. Chrome/WebKit에서는 표준 속성의 우선순위를 분리해 화살표를 제거하고, Firefox 및 고대비 모드는 기본 조작을 보존한다. 대기 단계는 진한 표면과 1px 경계·읽기 쉬운 숫자를 사용하며 현재/완료 단계와 API 상태는 유지한다.

새 브라우저 검사 6개는 수정 전에 모두 실패했다. 수정 후 실제 탐색·세로 스크롤·창 폭/높이·단계 경계 대비를 확인하고 전체 검증을 실행한다. 팀 #106이 병합돼 새 팀 PR을 만들고 개인 #1에 최신 프론트를 동기화해 Vercel에 재배포한다.
