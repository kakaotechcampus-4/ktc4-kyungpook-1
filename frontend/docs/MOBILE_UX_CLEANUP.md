# 모바일 화면 문구·간격 정리 (2026-09-23)

## 목표와 기준

320~390px에서 첫 행동이 한눈에 보이도록 한다. 동일한 사실은 같은 화면에서 한 번만 알리고, 저장 실패·권한·필수 입력처럼 결정에 필요한 정보는 유지한다. 카드 제목과 레포 이름처럼 길이가 달라지는 데이터는 화면 폭을 넘지 않게 한다.

## 화면별 결정

| 화면 | 변경 | 남긴 정보 |
|---|---|---|
| 로그인 | 체험 버튼을 누르면 바로 홈으로 이동. 모바일 예시 카드는 감춤. 소개 문구는 한 문장. | 체험 모드는 버튼 이름으로 표시. 실제 OAuth의 권한 안내는 모달에 유지. 만료·오류 안내는 유지. |
| 홈 | 시작 방법을 설명하는 중복 인트로 제거. 선택 링크를 `레포 고르기`, `직접 작성`으로 단축. | 레포 검색과 각 시작 경로의 차이. |
| 레포·카드 목록 | 상태 탭/필터와 겹치는 소제목 제거. 제목은 짧게, 카드 목록 모바일 조작은 검색 → 정렬·직접 작성 → 레포에서 만들기 순서. | 건수, 상태, 실패 시 재시도, 레포 선택 경고. |
| 직접 작성 | STAR 네 칸에 반복되던 사용자 출처 문구 제거. 입력 힌트와 저장·확정 조건을 단축. | 최초 저장 후 제목·기간·레포 잠금, 자동 저장 상태, 필요한 칸, 저장 실패. |

## 회귀 확인

- 320px 로그인: 버튼이 즉시 보이고, 긴 부연 설명과 예시 카드가 공간을 차지하지 않는다.
- 320px 카드 목록·직접 작성: 검색과 조작 버튼이 화면 밖으로 넘치지 않고 필드 입력이 가능하다.
- 390/768/1024/1440px 주요 라우트: 가로 넘침이 없다.
- 체험은 한 번의 버튼 클릭으로 시작하며, 실제 GitHub 권한 안내는 실제 연동 시에만 열린다.
- 서버 저장·분석·확정의 동작은 기존 E2E로 회귀 확인한다.

## 트러블슈팅

`body`에서 모바일에만 `word-break: normal`이 적용되어 한글 문장이 단어 중간에서 자주 끊겼다. 모바일에도 `keep-all`을 적용하고, 길이가 긴 식별자만 `overflow-wrap: break-word`로 필요한 경우에 끊는다. 가로 넘침 검사를 함께 돌려 긴 제목이 폭을 늘리지 않는지 확인한다.
