# SNS 공유 이미지 라이트 테마

## 범위와 구현
- 기존 구성과 문구를 유지하고 연한 초록 배경(#F2F7F4), 짙은 글자(#18251D), 초록 강조(#46704E), 원본 검정 로고를 사용합니다.
- OG와 Twitter는 사용자 테마와 무관한 하나의 1200×630 PNG를 사용합니다.
- 이미지 주소를 `/og/gitory-social-light-v2.png`로 바꿔 이전 이미지 캐시와 구분합니다. 기존 v1 파일은 이전 공유 링크 호환을 위해 남깁니다. SNS가 페이지 메타데이터를 캐시한 경우 해당 서비스에서 다시 수집해야 할 수 있습니다.
- 생성 스크립트는 수동 실행하며 운영 빌드에 브라우저 설치를 추가하지 않습니다.

## 검증 계획
1. 생성 PNG의 로고·글자·여백을 직접 확인합니다.
2. 메타데이터 단위 테스트와 정적 빌드 SEO E2E로 URL, PNG 형식과 크기, 비공개 화면 noindex를 검증합니다.
3. 배포 후 운영 HTML의 OG·Twitter 이미지 주소와 실제 이미지 응답을 확인합니다.

## 보존 사항
인트로·로그인·API 계약·테마 전환은 변경하지 않습니다. `.env`와 배포 인증 정보는 커밋하지 않습니다.

## 로컬 검증 결과
- 생성 PNG 직접 확인: 검정 로고, 초록 배경, 본문·강조 대비와 여백 정상.
- 메타데이터 단위 테스트 6개 통과.
- 프로덕션 빌드와 SEO E2E 3개 통과. 다른 개발 서버의 5173 포트를 건드리지 않고 전용 5439 포트로 실행했습니다.
