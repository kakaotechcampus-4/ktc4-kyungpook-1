# 사이드바 글자 대비

메뉴·그룹 제목·최근 카드 글자는 라이트에서 로고와 어울리는 먹색 `#171717`, 다크에서 기존 밝은 본문색을 사용한다. `--sidebar-text` 한 개로 관리하고 선택·hover에서도 같은 글자색을 유지한다. 선택 배경과 아이콘, 글자 굵기/자간, 본문·모바일 메뉴, API 동작은 그대로 유지한다.

기존 `shell.css`와 `layout-tio.css`의 역할별 색을 원래 규칙에서 교체한다. 두 테마의 펼침/접힘·최근 카드·hover와 작은 화면을 브라우저에서 확인하고 기존 대비/반응형 검사를 실행한다. 기존 팀 #106과 개인 #1을 갱신하고 Vercel에 재배포한다.
