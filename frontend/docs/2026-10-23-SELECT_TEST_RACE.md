# 2026-10-23 레포 선택 E2E 초기화 경합

## 증상과 원인
병합본 배포 전 전체 정적 E2E에서 151건 통과, 긴 레포 메뉴 검사 1건 실패했다. 키보드 도착 대상 repository-39 대신 기존 9개 레포가 표시됐다.
기본 `없음` 값은 조회 완료 이전에도 표시된다. 이 값만 기다린 뒤 sessionStorage를 바꾸면, 이전 문서에서 진행 중인 Mock 조회가 메모리 DB 스냅샷을 다시 저장해 테스트용 40개 레포를 덮어쓸 수 있다.

## 수정
기존 레포 목록 준비를 확인하고 다음 문서의 init script에서 40개 레포를 주입한다. 조회 후 메뉴 옵션 41개(없음 포함)를 기다린 다음 End 키를 누른다. 초점, 스크롤 범위, 선택 결과에 대한 기존 검증은 유지한다. 제품 코드와 백엔드 규약은 변경하지 않는다.

## 검증
검증 명령과 최종 결과는 PR에 기록한다.
수정 후 프로덕션 빌드에서 선택 메뉴 시나리오 3개를 각각 3회 반복해 9개 모두 통과했다. 병합본 단위 검사는 47개 파일/352개 통과했다.
