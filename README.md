# ktc4-team-05
카카오테크 캠퍼스 4기 2단계 팀 프로젝트 — 경북대 1팀

## 프론트엔드

`frontend/`는 GitHub 활동을 경험 카드로 정리하는 React 애플리케이션입니다. 로그인, 저장소 분석, 후보 선택, STAR 인터뷰, 카드 관리, 설정 화면을 포함합니다.

- 모바일 320px부터 데스크톱 1920px까지 반응형 레이아웃
- 모바일 상단 브랜드와 이름이 표시되는 하단 내비게이션
- 태블릿 축소 사이드바와 데스크톱 유동 작업 영역
- 백엔드 없이 전체 흐름을 확인할 수 있는 브라우저 목 API

```bash
cd frontend
npm install
npm run dev
```

검증 명령과 API 연동 방법은 [프론트엔드 README](frontend/README.md), 레이아웃 문제 기록은 [트러블슈팅 문서](docs/TROUBLESHOOTING.md)를 참고하세요.

`.env`, API 키, OAuth 토큰 등 민감정보는 저장소에 커밋하지 않습니다.
