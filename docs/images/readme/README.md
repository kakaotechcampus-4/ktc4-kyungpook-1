1. 운영 서비스에서 해당 화면을 열고 데이터 로딩이 끝난 것을 확인한다.
2. 민감한 정보가 없는지 확인하고, 브라우저 UI가 제외된 화면 원본을 저장한다.
3. 루트 README의 경로·대체 텍스트·기능 설명을 실제 화면과 대조한다.
4. 이 문서에 캡처일·대상·데이터 출처를 갱신하고, 모든 이미지를 직접 열어 확인한다.
