# 2026-10-24 소개 인트로 반복 재생

## 요구사항
소개 화면 진입/새로고침마다 로그인 여부와 관계없이 인트로를 재생한다. 모바일/PC 모두 동일하다. G가 중앙에 보이는 구간은 약 1.2배로 늘리되 헤더로 이동하는 속도와 최종 레이아웃은 유지한다.

## 변경 범위
- 기존 세션 viewed 플래그의 읽기/쓰기를 제거한다. 예전에 남은 플래그가 있어도 재생한다.
- 로그인 만료 및 동의 취소 안내에도 재생한다. 동의 모달을 직접 여는 경로, OS 동작 줄이기, 애니메이션 미지원 및 실패 복구는 유지한다.
- 중앙 구간 688ms→826ms, 이동 구간 912ms 유지: 전체 약 1.738초. 내용/배경 공개 시점도 추가 138ms에 맞춰 함께 이동한다.
- 홈·카드 등 앱 내부에는 인트로를 추가하지 않는다. API/SEO/로그인 계약은 변경하지 않는다.

## 검증 계획
기존 viewed 플래그와 로그인 상태를 준비한 재진입/새로고침 검사를 먼저 실패 확인한다. 모바일/PC의 800ms 시점 중앙 정렬, 종료 후 원래 헤더 위치, Escape/건너뛰기, 로그인·SEO 회귀를 확인한다. 기존 PR #393에 반영하고 Vercel 운영에서 다시 점검한다.
검증: 변경 전 legacy viewed 플래그가 있는 비로그인/로그인 브라우저 재생 검사 2개 실패 확인. 변경 후 인트로·반응형·로그인·SEO 회귀 33개 통과, 타입/프로덕션 빌드 통과. 모바일/PC 800ms 중앙 정렬 검사와 별도 코드 검토에서 문제 없음.
