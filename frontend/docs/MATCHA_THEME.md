# 아이비 가든 말차 · 말차 나이트 (2026-10-01)

사용자가 첨부한 두 팔레트를 공통 의미 토큰에 적용한다. 레이아웃·API·저장/확정 규칙은 변경하지 않는다.

| 역할 | 라이트 | 다크 |
|---|---|---|
| 기본 배경 | #F5F3EA | #12140F |
| 카드/메뉴 표면 | #FFFFFF | #1A1D16 |
| 주요 행동 | #4E6B2E | #A8C47C |
| 강한 그린/선택 표면 | #34481F / 부드러운 세이지 | #1F2719 |
| 장식·보조 강조 | #A9BC7E | #A8C47C |

버튼·STAR·확정 상태는 공통 강조색을 사용한다. 선택 메뉴는 연한 배경과 그린 글자, 선택 테두리는 강조색으로 표시한다.
근거 스트립은 라이트에서 진한 올리브, 다크에서 차분한 올리브 표면을 사용한다.
본문·작은 설명·주요 버튼은 읽기 대비를 확인한다. 주의(앰버)·오류(레드)는 별도 의미를 유지한다.
인쇄는 기존 흰 배경 규칙을 사용한다.

## 검증 범위
홈·카드·카드 상세·레포·랜딩을 라이트/다크와 390/1440px에서 캡처한 20장을 확인했다. 이 경로의 브라우저 pageerror는 0건이었다.

정적 프로덕션 빌드에서 `theme-contrast`·`responsive`·`product-polish` E2E 17개가 통과했다. 테마 기본 배경, 본문/보조 글자·버튼·선택 메뉴의 4.5:1 이상 대비, 320~1920px 가로 넘침, 선택 모서리/높이, 흰 로고, 모달 하단 동작을 확인한다. 색감 검사는 변경 전 두 테마에서 실패하고 변경 후 통과했다.

주요 버튼 대비는 라이트 6.06:1, 다크 9.58:1이다. 입력 경계는 배경 대비 3:1 이상이 되도록 별도 경계 토큰을 사용한다. 새 화면도 색을 직접 지정하지 않고 역할별 토큰을 사용한다.

설정 화면에서 실제 라디오 선택으로 다크 전환과 새로 진입 후 유지도 확인했다. 브라우저 오류는 없었다. 자동화 도구에서는 화면 아래 버튼을 클릭하기 전에 해당 영역을 스크롤해 클릭 위치를 확보했다.
