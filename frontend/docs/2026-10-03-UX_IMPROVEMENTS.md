# 8가지 UX 개선 계획 (2026-10-03)

## 목표와 범위
승인된 8가지 진단을 모바일/PC 화면에 반영한다. 세이지/다크 팔레트, 서버 저장, S/A 확정 조건, Job 폴링·멱등키·재시도 규약은 유지한다. 신규 라이브러리나 백엔드 변경은 없다.

## 최신 코드와 리뷰 기준
- `origin/develop` d6d07a6은 현재 브랜치에 포함돼 있다.
- #61의 리뷰 스레드 11건은 해결됐으며 10/2 최신 커밋 재검토 댓글을 확인했다. allSettled, action gate, 비동기 재조회, 선택 병합, 접근성 및 모달 정렬을 유지한다.
- #76은 현재 브랜치를 기반으로 만든 보완 커밋 69a70e7이다. 확정 후 상태 조회, 실제 빈칸/공백 판정, 보드 캐시 유지, 스피너·인쇄·포커스·짧은 화면 모달 수정을 먼저 통합하고 검증한다.
- #60도 검토했다. 현재 반영된 저장/이탈 보호를 유지하고 조회/입력 오류 문맥과 도메인 오류 안내를 보완한다. 과거 팔레트 복원이나 자동저장 내용의 취소·복구 기능을 무작정 도입하지 않는다.

## 작업 순서
1. **리뷰 보완 통합**: #76을 현재 격리 worktree에 반영하고 기존 단위 검사를 확인한다.
2. **행동·오류·작성 흐름**: `CardPage`, `CardModes`, `StarBlock`, `InterviewPage`, `CardsListPage`, `QueryFailure`, `errorView`, `cardRules`를 수정한다. 조회할 수 없는 건수는 `—`, 마지막 확인된 데이터는 유지한다. 칸별 수정은 해당 입력으로 이동한다. 보완할 항목을 주요 행동으로 표시하며 빈칸 확정은 기존 조건대로 가능하다.
3. **첫 진입·재방문·설정**: `LandingExample`, `HomePage`, `MyPage`, `LeavePage`를 수정한다. 모바일에서는 기록 한 개와 핵심 카드 예시를 함께 보여주고 전체 예시를 펼친다. 재방문 홈은 이어쓰기부터, 설정은 자주 쓰는 기능부터 보여준다. 공개/보관 정보는 펼쳐 확인할 수 있다.
4. **문구·공통 스타일**: 사용자에게 보이는 행동 이름을 실제 동작과 맞추고 불필요한 영어 플랜·내부 용어를 제거한다. 기존 의미 토큰과 공통 Button을 사용해 수정 버튼의 터치 영역을 확보한다.
5. **검증·문서·게시**: 의미 있는 조회 실패/입력 포커스/추천 행동/모바일 구성 E2E를 변경 전 실패→변경 후 통과로 확인한다. 타입·단위·정적 전체 E2E, 두 테마와 모바일/PC 시각 검증 및 별도 리뷰를 마친 후 README·트러블슈팅·두 PR·리뷰어·Vercel 운영 배포를 갱신한다.

## 검증에서 유지할 회귀 항목
- 저장 실패 시 입력/화면 유지, 이탈 가드, 사용자 답변 원문·출처, 마스킹 원문 보존.
- 후보 복원 부분 실패, 느린 재조회, 실행 취소 경합, 검색 중 선택 보존.
- 확정 필수 S/A와 실제 빈칸 안내, 성공 이후 DRAFT 버튼 재노출 방지.
- 모바일 하단 행동, 가로 넘침, 키보드 포커스, 로고·글자 대비·인쇄.
