# UX 개선 설계와 실행 기록

## 목적과 기준
최신 develop f6131ef에서 시작한다. 사용자가 승인한 10/18 UX 진단을 반영한다. 한 화면의 대표 행동을 명확히 하고, 입력을 보존하며 실제 제공 범위만 안내한다. PC 1440px, 모바일 390/320px에서 확인한다.

## 계약과 협업 경계
- API 경로, 요청/응답, Job enum·pollAfterMs·retryable, UUID 멱등키, null/400, STAR 저장·확정 규칙을 유지한다.
- #253의 진행 상태·재시도·사용된 후보 정리는 중복 구현하지 않는다. 필요한 경우 같은 파일의 다른 영역만 수정하고 결합 검증한다.
- #219 Docker 운영 스위치 및 #207/#116 기업 매칭은 변경하지 않는다.
- 역사 버전 본문을 조회하는 서버 계약이 없으면 본문을 지어내지 않는다. 서버 요약으로 복원 대상을 확인한 뒤 명시적 복원을 제공한다.
- 비밀정보·환경 파일을 커밋하지 않는다. 신규 의존성을 추가하지 않는다.
