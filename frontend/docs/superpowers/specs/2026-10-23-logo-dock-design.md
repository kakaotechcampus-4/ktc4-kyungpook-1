# Gitory 로고 도킹 인트로

사용자가 Wordmark Dock Preloader 방향을 승인했다. GitHub 푸시·PR·운영 도메인 변경 없이 Vercel preview로 먼저 검토한다.

중앙 워드마크가 약 1.4초 동안 페이드인되고 G 심볼이 미세하게 정렬된 뒤 기존 헤더 위치로 이동한다. 마지막 구간에 제목·설명·시작 버튼·예시가 순차적으로 열린다. 기존 이미지 로고·그린/다크 토큰을 사용하고 새 의존성은 추가하지 않는다.

320px에서는 중앙 로고 폭이 화면을 넘지 않게 제한한다. 재방문은 세션 내 생략하고 로그인 오류·만료·권한 안내에서는 즉시 기존 화면을 표시한다. 동작 줄이기 설정은 애니메이션을 생략한다. 검토 링크의 intro=1 쿼리는 매번 재생한다. 초기화 실패·애니메이션 취소에도 본문이 숨겨진 채 남지 않게 한다. 기존 로그인과 API는 변경하지 않는다.
후속 승인: 사용자가 디자인을 승인했고 PR 및 운영 배포를 요청했다. 위의 푸시/운영 보류는 최초 Preview 검토 단계의 조건이며 이후 작업은 docs/2026-10-23-BRAND_SEO.md를 따른다.
