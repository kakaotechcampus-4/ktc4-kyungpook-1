# 백엔드 프론트 요청 반영

## 범위
- #217: Job 오류 코드 `AI_UNAVAILABLE` 수용 및 일시 장애 안내.
- #254: 빈 저장소·내 프로필 README·비공개 저장소의 목록 제외 안내.

## 계약과 회귀 방지
새 오류 코드의 재시도 권한은 기존 공통 `retryable` 판정을 그대로 따른다. `true`일 때만 사용자가 다시 시도할 수 있으며 자동 분석 재실행은 하지 않는다. 실패 Job은 HTTP 정상 응답 본문으로 수용한다. 기존 GitHub 요청 한도 대기·멱등키·부분 완료 처리는 바꾸지 않는다.

목록 제외는 서버 책임이다. 프론트에서 커밋 수 0인 항목을 임의로 삭제하면 집계 전 저장소나 내 기여만 0인 팀 저장소가 사라질 수 있으므로 필터를 추가하지 않는다. 제외 안내는 검색·필터 결과 없음과 구분한 빈 목록 상태에만 표시한다.

## 검증
기능 구현 전 추가한 테스트 4개가 미지원 enum·누락 문구로 실패하는 것을 확인했다. 구현 후 새 코드 수용, retryable true/false/null, 자동 재실행 없음, 빈 목록 안내 및 기존 수집 상한/집계 전 표시를 함께 검증한다.
